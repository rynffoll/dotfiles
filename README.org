* Installation
Install [[https://brew.sh][Homebrew]].

Install [[https://mise.jdx.dev][mise]] and git:
#+begin_src sh
brew install mise git
#+end_src

Clone and bootstrap:
#+begin_src sh
git clone git@github.com:rynffoll/dotfiles.git ~/Developer/dotfiles
cd ~/Developer/dotfiles
mise trust
mise bootstrap
#+end_src
